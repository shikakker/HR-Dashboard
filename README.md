# HR Dashboard

HR Dashboard is a product prototype for recruitment and workforce workflows.

## Features

- Dashboard and analytics views.
- Export or download actions.

## Tech stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- Recharts

## Getting started

Requirements: Node.js 18+.

```bash
npm install
npm run dev
```

## Available scripts

- `npm run dev` — `vite`
- `npm run build` — `vite build`
- `npm run lint` — `eslint .`
- `npm run preview` — `vite preview`

## Status

Prototype or portfolio implementation. The documentation reflects the source currently present in this repository; production services and credentials are not included.
